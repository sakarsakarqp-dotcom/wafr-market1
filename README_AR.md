# وَفْر | WAFR — المرحلة الأولى

واجهة أولية عربية RTL لمنصة سوق متعددة المتاجر. تستخدم بيانات تجريبية فقط؛ لا توجد قاعدة بيانات أو حسابات أو طلبات أو دفع حقيقي في هذه المرحلة.

## المتطلبات
- Node.js 18.17 أو أحدث (يفضّل Node.js 20 LTS)
- npm

## التشغيل محليًا
1. فك ضغط المشروع.
2. افتح الطرفية داخل مجلد المشروع.
3. نفّذ:

```bash
npm install
npm run dev
```

4. افتح `http://localhost:3000`.

## فحص الإنتاج
```bash
npm run build
```

## ملاحظات
- لا تضف مفاتيح سرية إلى ملفات الواجهة.
- المرحلة الثانية المخطط لها: Supabase، المصادقة، قاعدة البيانات، التخزين وسياسات RLS.
- لا تنشر المنصة للجمهور قبل اختبار صلاحيات المستخدمين والطلبات.
