1) هذه ملفات المرحلة الأولى: واجهة عربية متجاوبة وبيانات منتجات تجريبية.
2) لا تحذف أي ملفات من داخل المجلد بعد فك الضغط.
3) للتشغيل على كمبيوتر: ثبّت Node.js 20 LTS، وافتح الطرفية داخل مجلد المشروع، ثم نفّذ:
   npm install
   npm run dev
4) افتح http://localhost:3000
5) لفحص البناء: npm run build

تنبيه: لم يتم ربط Supabase أو الحسابات أو الطلبات أو الدفع بعد. لا تعتبر النسخة جاهزة للإطلاق العام قبل الاختبار.
